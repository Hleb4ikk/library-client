# auth implementation

## что сделано

добавил страницу авторизации с формами логина и регистрации

- axios instance для api запросов
- zod схемы для валидации форм
- компонент authform принимает тип login или register
- страница с табами для переключения между формами
- api функции для отправки данных на сервер

## структура

```
src/
├── api/
│   ├── axios.ts
│   └── auth.api.ts
├── schemas/
│   └── auth.schema.ts
├── components/
│   └── AuthForm.tsx
└── pages/
    └── AuthPage.tsx
```

## как запустить

```bash
npm install
npm run dev
```

проект запустится на http://localhost:5173

## что работает

- переключение между формами логина и регистрации через табы
- валидация полей через zod
- отправка данных на /auth/login и /auth/register
- сохранение токена в localstorage
- показ ошибок если что-то не так

## валидация

login:
- email должен быть валидным
- пароль минимум 6 символов

register:
- имя от 2 до 50 символов
- email валидный
- пароль от 6 до 100 символов
- подтверждение пароля должно совпадать

## api

base url берется из .env файла, по дефолту http://localhost:3000/api

токен автоматически добавляется в хедеры если есть в localstorage

при 401 ошибке токен удаляется

axios.ts
 - настроенный axios instance с автодобавлением токена
auth.api.ts
 - функции loginUser() и registerUser() для апи запросов
auth.schema.ts
 - zod схемы валидации + типы через z.infer
AuthForm.tsx
 - универсальная форма, принимает type: "login" | "register"
AuthPage.tsx
 - страница с табами для переключения между формами

App.tsx
 - теперь рендерит AuthPage
