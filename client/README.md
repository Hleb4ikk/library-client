## project structure

```bash
client/
├── public/                 # Статичные файлы (иконка вкладки, шрифты)
├── src/
│   ├── api/                # Папка с вызовами нашего Api
│   ├── assets/             # Картинки, логотипы, глобальные стили
│   ├── public/             # Публичная папка с ассетами
│   ├── components/         # Общие UI-компоненты (кнопки, формы, инпуты)
│   ├── features/           # Логические модули (фичи) приложения
│   │   ├── auth/           # Всё для входа и регистрации
│   │   └── books/          # Всё для книг (каталог, карточки, поиск)
│   ├── layouts/            # Оболочки страниц (шапка сайта, подвал)
│   ├── pages/              # Сами страницы (Главная, Каталог, Профиль)
│   ├── routes/             # Настройка переходов между страницами
│   ├── services/           # Настройка запросов к бэкенду (Axios/Fetch)
│   ├── store/              # Глобальное состояние (Zustand/Redux)
│   ├── types/              # TypeScript типы и интерфейсы
│   ├── utils/              # Вспомогательные функции (формат дат, хелперы)
│   ├── App.tsx             # Главный компонент-обертка
│   └── main.tsx            # Точка запуска React-приложения
├── .env                    # Ссылка на ваш бэкенд и настройки
├── index.html              # Главный HTML-файл проекта
├── package.json            # Список библиотек и скрипты запуска
└── vite.config.ts          # Конфигурация сборщика Vite
```
