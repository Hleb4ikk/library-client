# Books API

Базовый префикс всех эндпоинтов: `/api/books`

Данные о книгах загружаются из [Open Library](https://openlibrary.org). Лайки и комментарии хранятся в локальной базе данных.

---

## GET `/api/books`

**Назначение:** поиск книг по ключевым словам, названию или автору.

**Примечания:**
- Публичный эндпоинт, авторизация не требуется.
- Результаты кешируются на сервере.

### Query-параметры

| Параметр | Тип      | Обязательный | По умолчанию | Описание |
|----------|----------|--------------|--------------|----------|
| `q`      | `string` | нет          | —            | Общий поисковый запрос (передаётся в Open Library как `q`). |
| `title`  | `string` | нет          | —            | Поиск по названию книги. |
| `author` | `string` | нет          | —            | Поиск по автору. |
| `page`   | `string` | нет          | `1`          | Номер страницы результатов. Должен быть положительным целым числом. |

Параметры `q`, `title` и `author` можно комбинировать. Хотя бы один из них рекомендуется указать для осмысленного поиска.

### Тело запроса

Отсутствует.

### Ответы

#### 200 OK — успех

```json
{
  "success": true,
  "message": "Книги успешно найдены",
  "data": {
    "books": [
      {
        "olid": "OL45883W",
        "title": "The Great Gatsby",
        "author": "F. Scott Fitzgerald",
        "cover_edition_key": "OL7352467M",
        "cover_url": "https://covers.openlibrary.org/b/olid/OL7352467M-M.jpg"
      }
    ],
    "total_results": 42,
    "page": 1
  }
}
```

| Поле                         | Тип             | Описание |
|------------------------------|-----------------|----------|
| `data.books`                 | `array`         | Список найденных книг. |
| `data.books[].olid`          | `string \| null`| Идентификатор работы в Open Library (без префикса `/works/`). |
| `data.books[].title`         | `string`        | Название книги. |
| `data.books[].author`        | `string`        | Автор(ы) через запятую или `"Неизвестный автор"`. |
| `data.books[].cover_edition_key` | `string \| null` | Ключ издания для обложки. |
| `data.books[].cover_url`     | `string \| null`| URL обложки (средний размер) или `null`. |
| `data.total_results`         | `number`        | Общее количество найденных книг. |
| `data.page`                  | `number`        | Текущая страница. |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "custom",
      "path": ["page"],
      "message": "Номер страницы должен быть положительным числом"
    }
  ]
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при поиске книг"
}
```

## GET `/api/books/:olid`

**Назначение:** получение подробной информации о книге по её OLID.

**Примечания:**
- Публичный эндпоинт, авторизация не требуется.
- Вместе с данными Open Library возвращает количество лайков и комментариев из локальной БД.
- Поле `is_liked` отражает, поставил ли текущий пользователь лайк (без авторизации всегда `false`).

### Query-параметры

Отсутствуют.

### Параметры пути

| Параметр | Тип      | Обязательный | Описание |
|----------|----------|--------------|----------|
| `olid`   | `string` | да           | Идентификатор работы в Open Library (например, `OL45883W`). |

### Тело запроса

Отсутствует.

### Ответы

#### 200 OK — успех

```json
{
  "success": true,
  "message": "Информация о книге успешно получена",
  "data": {
    "olid": "OL45883W",
    "title": "The Great Gatsby",
    "description": "A story of the fabulously wealthy Jay Gatsby...",
    "covers": [8231855],
    "cover_url": "https://covers.openlibrary.org/b/id/8231855-L.jpg",
    "likes_count": 12,
    "comments_count": 5,
    "is_liked": false
  }
}
```

| Поле                   | Тип       | Описание |
|------------------------|-----------|----------|
| `data.olid`            | `string`  | Идентификатор книги. |
| `data.title`           | `string`  | Название. |
| `data.description`     | `string`  | Описание или `"Описание отсутствует."`. |
| `data.covers`          | `number[]`| Массив ID обложек Open Library. |
| `data.cover_url`       | `string \| null` | URL обложки (большой размер) или `null`. |
| `data.likes_count`     | `number`  | Количество лайков. |
| `data.comments_count`  | `number`  | Количество комментариев. |
| `data.is_liked`        | `boolean` | Лайкнул ли текущий пользователь книгу. |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "too_small",
      "path": ["olid"],
      "message": "Идентификатор OLID обязателен"
    }
  ]
}
```

#### 404 Not Found — книга не найдена

```json
{
  "success": false,
  "message": "Книга не найдена в Open Library"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при получении информации о книге"
}
```

## GET `/api/books/:olid/comments`

**Назначение:** получение списка комментариев к книге с пагинацией.

**Примечания:**
- Публичный эндпоинт, авторизация не требуется.
- На одной странице — до 10 комментариев, отсортированных от новых к старым.

### Query-параметры

| Параметр | Тип      | Обязательный | По умолчанию | Описание |
|----------|----------|--------------|--------------|----------|
| `page`   | `string` | нет          | `1`          | Номер страницы. Должен быть положительным целым числом. |

### Параметры пути

| Параметр | Тип      | Обязательный | Описание |
|----------|----------|--------------|----------|
| `olid`   | `string` | да           | Идентификатор книги в Open Library. |

### Тело запроса

Отсутствует.

### Ответы

#### 200 OK — успех

```json
{
  "success": true,
  "message": "Комментарии успешно получены",
  "data": {
    "comments": [
      {
        "id": 1,
        "text": "Отличная книга!",
        "createdAt": "2026-06-13T10:00:00.000Z",
        "updatedAt": "2026-06-13T10:00:00.000Z",
        "user": {
          "id": 2,
          "username": "reader"
        }
      }
    ],
    "total_results": 15,
    "limit": 10,
    "page": 1
  }
}
```

| Поле                      | Тип       | Описание |
|---------------------------|-----------|----------|
| `data.comments`           | `array`   | Список комментариев. |
| `data.comments[].id`      | `number`  | ID комментария. |
| `data.comments[].text`    | `string`  | Текст комментария. |
| `data.comments[].createdAt` | `string` | Дата создания (ISO 8601). |
| `data.comments[].updatedAt` | `string` | Дата последнего изменения (ISO 8601). |
| `data.comments[].user.id` | `number`  | ID автора. |
| `data.comments[].user.username` | `string` | Имя автора. |
| `data.total_results`      | `number`  | Общее количество комментариев к книге. |
| `data.limit`              | `number`  | Размер страницы (всегда `10`). |
| `data.page`               | `number`  | Текущая страница. |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": []
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при получении комментариев"
}
```

## POST `/api/books/:olid/comments`

**Назначение:** добавление комментария к книге.

**Примечания:**
- **Требует авторизации** — заголовок `Authorization: Bearer <token>`.
- Комментарий привязывается к текущему авторизованному пользователю.

### Query-параметры

Отсутствуют.

### Параметры пути

| Параметр | Тип      | Обязательный | Описание |
|----------|----------|--------------|----------|
| `olid`   | `string` | да           | Идентификатор книги в Open Library. |

### Тело запроса

`Content-Type: application/json`

```json
{
  "text": "string"
}
```

| Поле   | Тип      | Обязательное | Описание |
|--------|----------|--------------|----------|
| `text` | `string` | да           | Текст комментария. От 1 до 2000 символов. |

### Ответы

#### 201 Created — успех

```json
{
  "success": true,
  "message": "Комментарий успешно добавлен",
  "data": {
    "id": 3,
    "text": "Очень понравилось",
    "createdAt": "2026-06-13T12:00:00.000Z",
    "updatedAt": "2026-06-13T12:00:00.000Z",
    "user": {
      "id": 1,
      "username": "john_doe"
    }
  }
}
```

| Поле                 | Тип      | Описание |
|----------------------|----------|----------|
| `data.id`            | `number` | ID созданного комментария. |
| `data.text`          | `string` | Текст комментария. |
| `data.createdAt`     | `string` | Дата создания (ISO 8601). |
| `data.updatedAt`     | `string` | Дата изменения (ISO 8601). |
| `data.user.id`       | `number` | ID автора. |
| `data.user.username` | `string` | Имя автора. |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "too_small",
      "path": ["text"],
      "message": "Комментарий не может быть пустым"
    }
  ]
}
```

#### 401 Unauthorized — не авторизован

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Не удалось сохранить комментарий в базе данных"
}
```

или

```json
{
  "success": false,
  "message": "Ошибка при добавлении комментария"
}
```

## POST `/api/books/:olid/like`

**Назначение:** переключение лайка книги (поставить / убрать).

**Примечания:**
- **Требует авторизации** — заголовок `Authorization: Bearer <token>`.
- Если лайк уже стоит — снимается; если нет — добавляется.
- После изменения сервер рассылает обновление количества лайков через WebSocket.

### Query-параметры

Отсутствуют.

### Параметры пути

| Параметр | Тип      | Обязательный | Описание |
|----------|----------|--------------|----------|
| `olid`   | `string` | да           | Идентификатор книги в Open Library. |

### Тело запроса

Отсутствует.

### Ответы

#### 200 OK — успех

```json
{
  "success": true,
  "message": "Статус лайка изменен",
  "data": {
    "is_liked": true,
    "likes_count": 13
  }
}
```

| Поле               | Тип       | Описание |
|--------------------|-----------|----------|
| `data.is_liked`    | `boolean` | Текущий статус лайка после операции. |
| `data.likes_count` | `number`  | Актуальное количество лайков у книги. |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": []
}
```

#### 401 Unauthorized — не авторизован

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при обработке лайка"
}
```
