# Comments API

Базовый префикс всех эндпоинтов: `/api/comments`

Все маршруты **требуют авторизации** — заголовок `Authorization: Bearer <token>`.

Редактировать и удалять можно только **свои** комментарии.

---

## PUT `/api/comments/:id`

**Назначение:** обновление текста существующего комментария.

**Примечания:**
- Доступно только автору комментария.
- Создание комментариев выполняется через `POST /api/books/:olid/comments`.

### Query-параметры

Отсутствуют.

### Параметры пути

| Параметр | Тип      | Обязательный | Описание |
|----------|----------|--------------|----------|
| `id`     | `string` | да           | Числовой ID комментария (передаётся в URL как строка, на сервере преобразуется в число). |

### Тело запроса

`Content-Type: application/json`

```json
{
  "text": "string"
}
```

| Поле   | Тип      | Обязательное | Описание |
|--------|----------|--------------|----------|
| `text` | `string` | да           | Новый текст комментария. От 1 до 2000 символов. |

### Ответы

#### 200 OK — успех

```json
{
  "success": true,
  "message": "Комментарий успешно обновлен",
  "data": {
    "id": 3,
    "text": "Исправленный текст комментария",
    "createdAt": "2026-06-13T12:00:00.000Z",
    "updatedAt": "2026-06-13T14:30:00.000Z",
    "user": {
      "id": 1,
      "username": "john_doe"
    }
  }
}
```

| Поле                 | Тип      | Описание |
|----------------------|----------|----------|
| `data.id`            | `number` | ID комментария. |
| `data.text`          | `string` | Обновлённый текст. |
| `data.createdAt`     | `string` | Дата создания (ISO 8601). |
| `data.updatedAt`     | `string` | Дата последнего изменения (ISO 8601). |
| `data.user.id`       | `number` | ID автора. |
| `data.user.username` | `string` | Имя автора. |

#### 400 Bad Request — ошибка валидации

Невалидный ID в пути или некорректное тело запроса.

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "custom",
      "path": ["id"],
      "message": "ID должен быть числом"
    }
  ]
}
```

или

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "too_big",
      "path": ["text"],
      "message": "Комментарий слишком длинный (максимум 2000 символов)"
    }
  ]
}
```

#### 401 Unauthorized — не авторизован

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

#### 403 Forbidden — не автор комментария

```json
{
  "success": false,
  "message": "Доступ запрещен: вы не являетесь автором этого комментария"
}
```

#### 404 Not Found — комментарий не найден

```json
{
  "success": false,
  "message": "Комментарий не найден"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Не удалось обновить комментарий"
}
```

или

```json
{
  "success": false,
  "message": "Ошибка при обновлении комментария"
}
```

## DELETE `/api/comments/:id`

**Назначение:** удаление комментария.

**Примечания:**
- Доступно только автору комментария.
- При успехе тело ответа отсутствует.

### Query-параметры

Отсутствуют.

### Параметры пути

| Параметр | Тип      | Обязательный | Описание |
|----------|----------|--------------|----------|
| `id`     | `string` | да           | Числовой ID комментария (передаётся в URL как строка, на сервере преобразуется в число). |

### Тело запроса

Отсутствует.

### Ответы

#### 204 No Content — успех

Комментарий удалён. Тело ответа пустое.

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "custom",
      "path": ["id"],
      "message": "ID должен быть числом"
    }
  ]
}
```

#### 401 Unauthorized — не авторизован

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

#### 403 Forbidden — не автор комментария

```json
{
  "success": false,
  "message": "Доступ запрещен: вы не являетесь автором этого комментария"
}
```

#### 404 Not Found — комментарий не найден

```json
{
  "success": false,
  "message": "Комментарий не найден"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при удалении комментария"
}
```
