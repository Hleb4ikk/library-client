# Auth API

Базовый префикс всех эндпоинтов: `/api/auth`

Авторизация для этих маршрутов **не требуется**.

---

## POST `/api/auth/register`

**Назначение:** регистрация нового пользователя в системе.

**Примечания:**
- Публичный эндпоинт, токен не нужен.
- При успешной регистрации пользователь **не** авторизуется автоматически — для получения JWT нужно вызвать `/api/auth/login`.

### Query-параметры

Отсутствуют.

### Тело запроса

`Content-Type: application/json`

```json
{
  "username": "string",
  "password": "string"
}
```

| Поле       | Тип      | Обязательное | Описание |
|------------|----------|--------------|----------|
| `username` | `string` | да           | Имя пользователя. Минимум 3 символа. |
| `password` | `string` | да           | Пароль. Минимум 6 символов, должен содержать строчную и заглавную букву, цифру и спецсимвол (`@$!%*?&`). |

### Ответы

#### 201 Created — успех

```json
{
  "success": true,
  "message": "Пользователь успешно создан",
  "data": {
    "id": 1,
    "username": "john_doe"
  }
}
```

| Поле            | Тип       | Описание |
|-----------------|-----------|----------|
| `success`       | `boolean` | Всегда `true` при успехе. |
| `message`       | `string`  | Текстовое сообщение об успешной операции. |
| `data.id`       | `number`  | ID созданного пользователя. |
| `data.username` | `string`  | Имя пользователя. |

#### 400 Bad Request — ошибка валидации

Возникает, если тело запроса не прошло проверку Zod-схемой.

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "too_small",
      "path": ["username"],
      "message": "Too small: expected string to have >=3 characters"
    }
  ]
}
```

| Поле          | Тип       | Описание |
|---------------|-----------|----------|
| `success`     | `boolean` | Всегда `false`. |
| `message`     | `string`  | `"Ошибка валидации"`. |
| `description` | `array`   | Массив объектов Zod (`issues`) с деталями по каждому невалидному полю. |

#### 409 Conflict — пользователь уже существует

```json
{
  "success": false,
  "message": "Пользователь с таким именем уже существует"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Не удалось создать пользователя"
}
```

или

```json
{
  "success": false,
  "message": "Ошибка при регистрации"
}
```

## POST `/api/auth/login`

**Назначение:** аутентификация пользователя и выдача JWT access-токена.

**Примечания:**
- Публичный эндпоинт, токен не нужен.
- Полученный `token` передаётся в заголовке `Authorization: Bearer <token>` для защищённых маршрутов (например, `/api/me/*`).

### Query-параметры

Отсутствуют.

### Тело запроса

`Content-Type: application/json`

```json
{
  "username": "string",
  "password": "string"
}
```

| Поле       | Тип      | Обязательное | Описание |
|------------|----------|--------------|----------|
| `username` | `string` | да           | Имя пользователя. Минимум 3 символа. |
| `password` | `string` | да           | Пароль. Минимум 6 символов, должен содержать строчную и заглавную букву, цифру и спецсимвол (`@$!%*?&`). |

### Ответы

#### 200 OK — успех

```json
{
  "success": true,
  "message": "Успешный вход",
  "data": {
    "user": {
      "id": 1,
      "username": "john_doe"
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

| Поле              | Тип       | Описание |
|-------------------|-----------|----------|
| `success`         | `boolean` | Всегда `true` при успехе. |
| `message`         | `string`  | Текстовое сообщение об успешной операции. |
| `data.user.id`    | `number`  | ID пользователя. |
| `data.user.username` | `string` | Имя пользователя. |
| `data.token`      | `string`  | JWT access-токен (алгоритм HS256). |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "invalid_format",
      "path": ["password"],
      "message": "Invalid string: must match pattern /^(?=.*[a-z])..."
    }
  ]
}
```

| Поле          | Тип       | Описание |
|---------------|-----------|----------|
| `success`     | `boolean` | Всегда `false`. |
| `message`     | `string`  | `"Ошибка валидации"`. |
| `description` | `array`   | Массив объектов Zod (`issues`) с деталями по каждому невалидному полю. |

#### 401 Unauthorized — неверные учётные данные

```json
{
  "success": false,
  "message": "Неверное имя пользователя или пароль"
}
```

Сообщение одинаковое, если пользователь не найден или пароль неверен.

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при авторизации"
}
```
