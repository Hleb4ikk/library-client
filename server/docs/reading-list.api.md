# Reading List API

Базовый префикс всех эндпоинтов: `/api/reading-list`

Все маршруты **требуют авторизации** — заголовок `Authorization: Bearer <token>`.

Список чтения привязан к текущему пользователю. Каждая книга может быть добавлена только один раз (уникальная пара `userId` + `book_olid`).

### Допустимые статусы

| Значение          | Описание |
|-------------------|----------|
| `Хочу прочитать`  | Книга в планах |
| `Читаю сейчас`    | Книга читается в данный момент |
| `Прочитано`       | Книга прочитана |

---

## GET `/api/reading-list`

**Назначение:** получение списка книг текущего пользователя с пагинацией и опциональной фильтрацией по статусу.

**Примечания:**
- Возвращает только записи авторизованного пользователя.
- Для каждой записи подтягиваются название и обложка из Open Library.

### Query-параметры

| Параметр | Тип      | Обязательный | По умолчанию | Описание |
|----------|----------|--------------|--------------|----------|
| `status` | `string` | нет          | —            | Фильтр по статусу. Одно из: `Хочу прочитать`, `Читаю сейчас`, `Прочитано`. Без параметра — все записи. |
| `page`   | `string` | нет          | `1`          | Номер страницы. Должен быть положительным целым числом. |
| `limit`  | `string` | нет          | `4`          | Количество записей на странице. Должен быть положительным целым числом. |

### Тело запроса

Отсутствует.

### Ответы

#### 200 OK — успех

```json
{
  "success": true,
  "message": "Список чтения успешно получен",
  "data": {
    "items": [
      {
        "id": 1,
        "book_olid": "OL45883W",
        "status": "Читаю сейчас",
        "created_at": "2026-06-13T10:00:00.000Z",
        "updated_at": "2026-06-13T12:00:00.000Z",
        "title": "The Great Gatsby",
        "cover": "https://covers.openlibrary.org/b/id/8231855-L.jpg"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 4,
      "total": 10,
      "totalPages": 3
    }
  }
}
```

| Поле                        | Тип             | Описание |
|-----------------------------|-----------------|----------|
| `data.items`                | `array`         | Список записей списка чтения. |
| `data.items[].id`           | `number`        | ID записи в списке чтения. |
| `data.items[].book_olid`    | `string`        | OLID книги в Open Library. |
| `data.items[].status`       | `string`        | Текущий статус книги. |
| `data.items[].created_at`   | `string`        | Дата добавления (ISO 8601). |
| `data.items[].updated_at`   | `string \| null`| Дата последнего изменения статуса (ISO 8601). |
| `data.items[].title`        | `string`        | Название книги из Open Library. |
| `data.items[].cover`        | `string \| null`| URL обложки или `null`. |
| `data.pagination.page`      | `number`        | Текущая страница. |
| `data.pagination.limit`     | `number`        | Размер страницы. |
| `data.pagination.total`     | `number`        | Общее количество записей (с учётом фильтра `status`). |
| `data.pagination.totalPages`| `number`        | Общее количество страниц. |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "invalid_value",
      "path": ["status"],
      "message": "Невалидный статус"
    }
  ]
}
```

#### 401 Unauthorized — не авторизован

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при получении списка чтения"
}
```

## POST `/api/reading-list`

**Назначение:** добавление книги в список чтения или обновление статуса уже добавленной книги.

**Примечания:**
- Если книга с таким `book_olid` уже есть у пользователя — обновляется только `status` (ответ **200**).
- Если книги ещё нет — создаётся новая запись (ответ **201**).

### Query-параметры

Отсутствуют.

### Тело запроса

`Content-Type: application/json`

```json
{
  "book_olid": "string",
  "status": "string"
}
```

| Поле        | Тип      | Обязательное | Описание |
|-------------|----------|--------------|----------|
| `book_olid` | `string` | да           | OLID книги в Open Library. Минимум 1 символ. |
| `status`    | `string` | да           | Статус: `Хочу прочитать`, `Читаю сейчас` или `Прочитано`. |

### Ответы

#### 201 Created — книга добавлена

```json
{
  "success": true,
  "message": "Книга добавлена в список чтения",
  "data": {
    "id": 2,
    "userId": 1,
    "bookOlid": "OL45883W",
    "status": "Хочу прочитать",
    "createdAt": "2026-06-13T14:00:00.000Z",
    "updatedAt": null
  }
}
```

#### 200 OK — статус обновлён

```json
{
  "success": true,
  "message": "Статус книги обновлён",
  "data": {
    "id": 2,
    "userId": 1,
    "bookOlid": "OL45883W",
    "status": "Прочитано",
    "createdAt": "2026-06-13T14:00:00.000Z",
    "updatedAt": "2026-06-13T16:00:00.000Z"
  }
}
```

| Поле              | Тип              | Описание |
|-------------------|------------------|----------|
| `data.id`         | `number`         | ID записи в списке чтения. |
| `data.userId`     | `number`         | ID пользователя-владельца. |
| `data.bookOlid`   | `string`         | OLID книги. |
| `data.status`     | `string`         | Текущий статус. |
| `data.createdAt`  | `string`         | Дата создания записи (ISO 8601). |
| `data.updatedAt`  | `string \| null` | Дата последнего обновления статуса. |

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "invalid_value",
      "path": ["status"],
      "message": "Невалидный статус"
    }
  ]
}
```

#### 401 Unauthorized — не авторизован

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Не удалось добавить книгу в список чтения"
}
```

или

```json
{
  "success": false,
  "message": "Не удалось обновить статус книги"
}
```

или

```json
{
  "success": false,
  "message": "Ошибка при сохранении записи в списке чтения"
}
```

## DELETE `/api/reading-list/:id`

**Назначение:** удаление записи из списка чтения.

**Примечания:**
- Доступно только владельцу записи.
- При успехе тело ответа отсутствует.

### Query-параметры

Отсутствуют.

### Параметры пути

| Параметр | Тип      | Обязательный | Описание |
|----------|----------|--------------|----------|
| `id`     | `string` | да           | Числовой ID записи в списке чтения (передаётся в URL как строка). |

### Тело запроса

Отсутствует.

### Ответы

#### 204 No Content — успех

Запись удалена. Тело ответа пустое.

#### 400 Bad Request — ошибка валидации

```json
{
  "success": false,
  "message": "Ошибка валидации",
  "description": [
    {
      "code": "custom",
      "path": ["id"],
      "message": "ID должен быть числом"
    }
  ]
}
```

#### 401 Unauthorized — не авторизован

```json
{
  "success": false,
  "message": "Unauthorized"
}
```

#### 403 Forbidden — не владелец записи

```json
{
  "success": false,
  "message": "Доступ запрещен: вы не являетесь владельцем этой записи"
}
```

#### 404 Not Found — запись не найдена

```json
{
  "success": false,
  "message": "Запись не найдена"
}
```

#### 500 Internal Server Error — ошибка сервера

```json
{
  "success": false,
  "message": "Ошибка при удалении записи из списка чтения"
}
```
